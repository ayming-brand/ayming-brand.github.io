Ajouter des images

Le portail garde les assets de marque réutilisables ; les documents de travail d'un deck (photo propre à un client, capture d'écran ponctuelle) restent dans le repo assets et continuent de servir leur deck sans jamais s'afficher ici. Deux façons d'ajouter un fichier réutilisable, jamais depuis cette page.

  • Donner les fichiers à Claude dans le chat, avec le dossier cible (ex. imagery/mon-offre/).
  • Les déposer via l'interface web de GitHub dans ayming-france/assets, sous imagery/<dossier>.

La prochaine régénération du portail les indexe automatiquement.

  • vm-logos Grille de logos d'intégrations SIRH, 2 decks, sous le seuil.
  • pricing 3 decks ont une slide tarification mais trois modèles différents (plan mensuel essentiel, grille de points abo-dat, success-fee es-cotizaciones). Trois significations distinctes, pas de composant générique honnête.
  • stat-row-standalone 3 decks, et la slide introduction porte déjà les cartes de chiffres. Pas d'archétype séparé.
  • variantes-chaine-locales remboursements-ijss (dimensionnement 3 maillons) et arrets-longue-duree (chorégraphie d'entrée propre) gardent leurs surcharges locales par-dessus la chaîne promue.

  • charges-sociales-responsive Bloc media query de charges-sociales qui resserre 25 classes moteur pour les écrans portables 1366x768. Candidat à entrer dans slides.css lui-même, décision moteur séparée, hors périmètre composants.
